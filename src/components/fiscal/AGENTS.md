- Fiscal guides in cadastros and pre-emission reuse the exported page editors (ProductEditDrawer, MicroorganismEditDrawer, CustomerFiscalEditDrawer, ServiceFiscalEditDrawer) with each page's own permission rule; viewing never creates a profile and pendencies come only from src/lib/fiscal/preEmissionPendencies.ts — prevents parallel editors and divergent classifiers.
- CST vs CSOSN by CRT is decided only by supabase/functions/_shared/fiscal/nfe/icmsRegime.ts (CRT 1/4 CSOSN, 2/3 CST), shared by the XML engine and the app — prevents engine/UI drift.
- Draft CFOP autofill comes only from src/lib/fiscal/draftCfopSelection.ts: needs emitter+recipient UF, issue date, sale operation and normal purpose, otherwise stays empty; re-evaluation runs only after a user pick in the wizard and never overwrites manual CFOPs — prevents presumed internal operations and changing existing notes.
- Owned-product fiscal write needs canWriteOwnedProduct (tenant admin/gestor) plus per-item ownership confirmed by useOwnedProductIds (produtos.owner_organization_id = actor org), saving only via tenant_owned_product_fiscal_save — prevents editing foreign/global products while the server stays authoritative.
